# data-science-internship-project-2

## Supervised Learning: Fraud Detection Pipeline

This project is part of my **Data Science Industrial Training at DecodeLabs (Batch 2026)**.

The project focuses on building a **Supervised Learning Fraud Detection Pipeline** to identify fraudulent transactions in a highly imbalanced dataset. The required workflow includes SMOTE, Logistic Regression, Random Forest, and evaluation using Precision, Recall, and ROC-AUC.

##  Development Environment

This project was developed and executed using **Jupyter Notebook**.

The complete machine learning workflow is implemented inside the Jupyter Notebook, including:

1. Data loading
2. Data preprocessing
3. Exploratory Data Analysis (EDA)
4. Feature preparation
5. Handling class imbalance with SMOTE
6. Model training
7. Logistic Regression
8. Random Forest
9. Hyperparameter tuning
10. Model evaluation
11. Precision, Recall, and ROC-AUC analysis

##  How to Run

### 1. Clone the repository

```bash
git clone https://github.com/NaseerAhmed112/data-science-internship-project-2.git
cd data-science-internship-project-2
```

### 2. Install dependencies

```bash
pip install pandas numpy scikit-learn imbalanced-learn matplotlib seaborn jupyter
```

### 3. Start Jupyter Notebook

```bash
jupyter notebook
```

### 4. Open the Project Notebook

Open:

```text
Fraud_Detection_Project_2.ipynb
```

Then run the notebook cells sequentially.
